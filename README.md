# DDLib Open Source


[![MIT License](https://img.shields.io/github/license/Double-Dig-IT/DDLib?color=%230b0&style=flat-square)](https://github.com/Double-Dig-IT/DDLib/blob/master/LICENSE)

DDLib is the open-source core framework for all ddigit software, such as Collection Manager, Collection Publisher and Collection Mobile.
DDLib runs on [.NET](https://dot.net), a free, cross-platform, and open-source application runtime. [Learn more about about the DDigit Collection Software](https://ddigit.eu/).
